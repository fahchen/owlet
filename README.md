## 视觉与交互原型

直接在浏览器打开 [design/index.html](design/index.html)。HTML、CSS、JavaScript 和图标均内嵌于同一文件，无安装步骤或网络依赖。

即时处理使用 macOS Spotlight 风格的浮动工具栏，设置、生词本和历史使用完整管理窗口。

原型使用中英日内置样例，提供翻译、润色、学习内容展开、勾选收藏、生词本编辑／导出、历史及设置。独立的“翻译并替换”入口只修改页面内模拟原选区。右上角可切换请求失败与选区失效场景。

原型的窗口骨架与控件都已经换成 macOS 26 原生组件的外观：可收起的系统侧边栏，跨整窗的统一工具栏（目标语言弹出式按钮、翻译／润色分段控件、trailing 端的唯一 prominent 动作），内容区的系统搜索框、分组表单、开关与空状态。文本处理页在内容区足够宽时把原文与译文左右并排，不足 720px 时改回上下堆叠。每个组件到原生 SwiftUI / AppKit 组件的对照，以及仍保留自定义的四处例外，见 [Liquid Glass 组件对照](docs/liquid-glass-components.md)。

界面文案遵循三条规则：动作区只放动作，不放解释性文字；不把快捷键画进界面（快捷键归菜单栏与悬停提示）；按钮只用动词，宾语交给同一屏的上下文（`翻译`、`复制`、`保存`、`收藏`、`导出…`）。

快捷键无默认组合，录制后页面内可用；Esc 关闭；收藏、历史和普通设置保存于浏览器本地。API Key 不保存，也不调用模型。任意文本翻译、系统快捷键和 macOS 跨应用替换留待原生实现。

### 原型检查

在浏览器打开文件后依次操作：

1. 展开学习内容，勾选“move forward”并收藏；在生词本确认条目，修改释义并刷新验证保存。
2. 点击“翻译并替换”，确认模拟原选区被译文替换。
3. 选择“原选区已变化”并再次执行，确认拒绝写回且译文可复制。
4. 选择“请求失败”并重新翻译，确认错误提示；处理期间取消，确认无迟到写回。
5. 设置中开启翻译学习，返回翻译确认自动展开；检查润色开关保持独立。
6. 检查历史与收藏的搜索、删除、导出，以及清空历史不影响收藏。

BDD 场景尚未绑定自动化步骤；原生应用尚未开始实现。

## 状态设计预览

页面上方的“状态预览”可直接切换 42 种状态，左右箭头逐个浏览。状态总览按窗口与面板分组：紧凑条、展开面板、学习区块、文本处理、生词本、历史、快捷键、设置、菜单栏九组竖向堆叠，同一面板内的状态横向排列。状态预览不清空已有收藏或历史；空列表、已收藏等使用展示态。真实演示操作仍保存在浏览器中。

- 文本处理：无选区输入、处理中、翻译结果、长文本、润色结果、修改对照。
- 学习与收藏：展开、整理中、生成失败、无推荐、已入库。
- 写回：直接替换处理中、完成、选区失效。
- 异常与退出：请求失败、已取消、未授权、服务未配置、浮层收起。
- 管理：生词本为空、历史为空、搜索无结果。

浮层宽 560px，标题栏 40px，底部操作栏至少 45px。内容增长时内部滚动，复制／替换仍固定可见。浮层是功能层，材质集中在这里；内容层不叠玻璃。网页材质是视觉近似；原生 `NSGlassEffectView` 的折射与系统辅助功能适配在 macOS 实现阶段调校。

浏览器控制台运行 `checkDesignStates()` 可检查全部预览是否有操作栏、是否使用正确浮层及是否发生底部裁切。检查不修改持久化数据。

翻译结果默认按原文与译文分区显示；设置中可改为逐句对照，每组上方原文、下方译文。长文本按句组滚动；复制和替换只取译文。原型使用显式配对的样例数据，不以标点或显示行数猜测对应关系。

处理中使用约 430px 宽的单行紧凑条：整圈边框呼吸灯、选中文字摘要、状态文字。不显示结果占位区、学习推荐、完整操作栏或终止按钮；按 `spec/product.md`，Esc 关闭并取消本次操作。呼吸只作用于玻璃面板自身的描边与边缘阴影，单色、无渐变；展开态重新处理时同样是整圈呼吸，边框静止时不丢失标记。翻译／润色完成后，以约 280ms 的缩放与淡入展开结果；系统开启“减少动态效果”时呼吸静止为稳定亮边，展开直接切换。

浮层外观以 macOS Tahoe Spotlight 为参考：中性半透明材质、细边缘、柔和悬浮阴影、单行处理条及下方结果展开。保留 Owlet 的翻译与润色动作，不复制搜索功能；网页材质是视觉近似，非系统原生渲染。参考：[Apple macOS Tahoe](https://www.apple.com/newsroom/2025/06/macos-tahoe-26-makes-the-mac-more-capable-productive-and-intelligent-than-ever/)。

设置中可分别查看、编辑翻译／润色 System Prompt，恢复默认后点击保存生效。浏览器重启保留自定义值。JSON 返回示例可展开查看，状态预览含“JSON 格式错误”。默认 Prompt 与原生 JSON 契约见 [spec/llm/contract.md](spec/llm/contract.md)；原型仍不请求真实模型。

快捷键设置支持点击录制、Esc 取消、Delete／清除按钮清除，无默认组合；检查三个动作之间的组合冲突，保存后生效并在浏览器中持久化。系统级占用与全局注册由原生应用处理。

快捷键录制检查：初始三个动作均为“未设置”且按键不触发。录制翻译为 ⌃⌥T、润色为 ⌃⌥P，保存并刷新，确认各自唤起；为翻译录制 ⌃⌥P 应提示冲突；Esc 取消且设置窗口保留；点击清除或 Delete 并保存后不再触发。JSON 契约见 spec/llm/contract.md。

完整窗口左侧统一为“文本处理”，在同一页面选择翻译／润色，输入后执行并复制结果。侧边栏可以收起，收起后工具栏与功能不变。没有两个操作 tab，也不提供“翻译并替换”导航项。浮层仍保留三个快捷入口，页内结果不写回外部选区。

界面文案仅保留功能标签、内容和必要状态／错误提示，移除介绍性标题、副标题和重复操作说明；图标保留可访问名称。

原型默认打开“状态总览”，按窗口与面板分组展示所有状态画面；右上角可调缩放，每个画面的 ↗ 可进入交互。`checkFlowBoard()` 检查 42 个状态是否全部出现、是否有重复，以及分组数是否与定义一致。

学习表达默认手动：点击“生成”才模拟独立请求；设置中的翻译／润色“自动请求学习表达”开关可改为每次处理成功后自动请求。收起后再次展开复用本次结果。复制、替换使用透明玻璃按钮，重新处理位于浮窗右上角，`收藏选中内容` 位于动作行左端。
