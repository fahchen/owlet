## 视觉与交互原型

直接在浏览器打开 [design/index.html](design/index.html)。HTML、CSS、JavaScript 和图标均内嵌于同一文件，无安装步骤或网络依赖。

原型使用中英日内置样例，提供翻译、润色、学习内容展开、勾选收藏、生词本编辑／导出、历史及设置。独立的“翻译并替换”入口只修改页面内模拟原选区。右上角可切换请求失败与选区失效场景。

支持页面内 Option+T/P/R、Esc 关闭；收藏、历史和普通设置保存于浏览器本地。API Key 不保存，也不调用模型。任意文本翻译、系统快捷键和 macOS 跨应用替换留待原生实现。

### 原型检查

在浏览器打开文件后依次操作：

1. 展开学习内容，勾选“move forward”并收藏；在生词本确认条目，修改释义并刷新验证保存。
2. 点击“翻译并替换”，确认模拟原选区被译文替换。
3. 选择“原选区已变化”并再次执行，确认拒绝写回且译文可复制。
4. 选择“请求失败”并重新翻译，确认错误提示；处理期间取消，确认无迟到写回。
5. 设置中开启翻译学习，返回翻译确认自动展开；检查润色开关保持独立。
6. 检查历史与收藏的搜索、删除、导出，以及清空历史不影响收藏。

BDD 场景尚未绑定自动化步骤；原生应用尚未开始实现。
