## Proposals not yet in the product definition

- **iCloud sync.** Notebook, contexts, history and a whitelist of settings across the user's Macs through a CloudKit private database; off by default and needing a team-signed build. Moves sync out of "Not in the first version". See [icloud-sync.md](icloud-sync.md).
- **User-defined word blocks.** A word's dictionary content is generated by the model and laid out in sections the user defines, in the lookup card and the notebook entry, with a bulk update across saved words. LLM only; no local dictionary source this round. See [dictionary-blocks.md](dictionary-blocks.md).
- **Manual input in the panel.** A failed read opens the panel as an empty editor instead of a prompt, and text already read gets an explicit edit entry. Changes `spec/product.md` and BDR-0002 if accepted. See [manual-input.md](manual-input.md).
- **Screen region OCR input.** Draw a rectangle on screen and read its text with Vision; copy only, nothing to write back. See [screen-region-input.md](screen-region-input.md).
- **Continuous speech input.** See [speech-input.md](speech-input.md). Not planned for now.

## Not in the first version

Review, spaced repetition and mastery tracking; automatic collection; sync and accounts; multiple polish variants and tone presets. See [product.md](../spec/product.md), *Not in the first version*.
