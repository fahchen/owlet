# Owlet · Rose Glass

浅色玫瑰粉主题，用于白天阅读与工作沟通中短暂唤起的语言工具。保留系统字体、紧凑布局与 Liquid Glass 材质。

| 角色 | OKLCH | 用途 |
|---|---|---|
| 玫瑰强调 | 47% .17 350 | 主按钮、焦点、开关、选中状态 |
| 花瓣浅粉 | 95% .025 350 | 选中背景与浅色容器 |
| 深色正文 | 27% .01 350 | 正文与标题 |
| 灰玫瑰 | 45% .01 350 | 标签与次要文字 |
| 近白底色 | 99% .003 350 | 应用内容与控件 |

粉色只负责品牌与交互强调。成功保留绿色，错误保留暖红，避免与品牌粉混淆。浮窗使用半透明浅粉与白色边缘反光，复制按钮近白，替换按钮带玫瑰色染色。处理中沿用整圈呼吸灯，改为粉色光。减少动态效果时保持静态边框。
