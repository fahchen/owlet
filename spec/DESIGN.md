# Owlet · Rose Glass

中性浅色界面，玫瑰粉作为 primary color，用于白天阅读与工作沟通中短暂唤起的语言工具。保留系统字体、紧凑布局与 Liquid Glass 材质。

| 角色 | OKLCH | 用途 |
|---|---|---|
| 玫瑰强调 | 47% .17 350 | 主按钮、焦点、开关、选中状态 |
| 花瓣浅粉 | 95% .025 350 | 选中背景，不用于通用背景 |
| 深色正文 | 27% .008 265 | 正文与标题 |
| 中性次要文字 | 45% .008 265 | 标签与次要文字 |
| 近白底色 | 99% .003 265 | 应用内容与控件 |

粉色只负责品牌与交互强调。成功保留绿色，错误保留暖红，避免与品牌粉混淆。背景、玻璃面板与正文保持中性灰白；玫瑰色集中在主按钮、选中态、焦点与处理中指示。复制按钮近白，替换按钮使用深玫瑰色与浅色文字，形成视觉主导。处理中沿用整圈呼吸灯，改为粉色光。减少动态效果时保持静态边框。

译文仅比原文大 1px：浮动工具栏原文 12px、译文 13px；app 内原文 16px、译文 17px。分区与逐句对照一致，润色结果沿用同一层级。
