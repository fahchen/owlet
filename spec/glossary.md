# 产品术语

以下定义沿用已确认的产品用语。

| 术语 | 定义 |
|---|---|
| 原选区 | 用户触发操作时，来源应用中选中的文本及对应位置；不等同于后来获得焦点的输入框。 |
| 翻译 | 将文本转换为目标语言，普通入口先展示结果。 |
| 润色 | 保持语言与原意，修正语法和改善自然度。 |
| 翻译并替换 | 一次明确触发翻译，并在结果生成后直接写回原选区。 |
| 目标映射 | 用户配置的「源语言 → 目标语言」规则，用于在没有显式指定目标语言时决定翻译目标；一个源语言只对应一个目标。 |
| 兜底目标 | 映射中没有对应源语言或无法可靠检测源语言时使用的目标语言，默认简体中文。 |
| 学习内容 | 可选生成的词汇、搭配、句式与中文解释，不等于收藏。 |
| 收藏条目 | 用户主动保存的表达，词汇、短语和整句统一处理。 |
| 语境 | 收藏表达出现的原句、对应释义，以及适用时的润色前后对照。 |
| 生词本 | 用户收藏的统一列表，不代表其中内容都未掌握。 |
| 历史 | 翻译与润色已生成结果的本地记录，不持有原选区的写回权限。 |
