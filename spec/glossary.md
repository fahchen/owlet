# Product Glossary

The definitions below follow the confirmed product terminology.

| Term | Definition |
|---|---|
| Original selection | The text selected in the source app when the user triggers an operation, and its position; not the same as an input field that gains focus later. |
| Translate | Converts text into the target language; the normal entry shows the result first. |
| Polish | Keeps the language and meaning, fixes grammar and improves naturalness. |
| Translate and Replace | One explicit trigger that translates and writes the result back to the original selection as soon as it is generated. |
| Polish and Replace | One explicit trigger that polishes and writes the result back to the original selection as soon as it is generated. |
| Target mapping | The user's "source language → target language" rules, used to decide the translation target when no target language was chosen explicitly; one source language maps to exactly one target. |
| Fallback target | The target language used when the mapping has no row for the source language or the source language cannot be detected reliably; Simplified Chinese by default. |
| Study content | Optionally generated words, collocations, sentence patterns and meanings; not the same as collected items. |
| Collected entry | An expression the user chose to save; words, phrases and whole sentences are handled the same way. |
| Context | The source sentence where a collected expression appeared, its meaning there, and the before / after comparison for polish when applicable. |
| Notebook | The single list of what the user collected; it does not imply that everything in it is unlearned. |
| Meaning | An explanation of what an expression means, generated by the model and editable by the user; overwritten on regeneration. Its language is computed from the current mapping at generation time: translation follows this operation's target, polish looks up the source language in the mapping. The entry records the language the stored meaning is actually written in. |
| Notes | The user's handwritten personal remarks, stored separately from the meaning; automatic flows never touch them. |
| Tag | A free-form category word the user adds to entries; it disappears naturally when no entry references it. |
| Starred | A binary flag the user sets on an entry, used for filtering; it does not indicate mastery. |
| Reading | The pronunciation notation of an expression; the notation (IPA / kana / pinyin / romaji) is configured per language in settings and saved with the entry. |
| Part of speech | The grammatical category of an expression; not set for whole sentences. |
| History | The local record of generated translate and polish results; it holds no write-back permission for the original selection. It records the app the text came from and links to entries collected from that record. |
| Source | Where a collected entry came from: the entry point (selection / study suggestion / history) and the app the text came from; kept when history is deleted. |
