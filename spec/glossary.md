# 产品术语

以下定义沿用已确认的产品用语。

| 术语 | 定义 |
|---|---|
| 原选区 | 用户触发操作时，来源应用中选中的文本及对应位置；不等同于后来获得焦点的输入框。 |
| 翻译 | 将文本转换为目标语言，普通入口先展示结果。 |
| 润色 | 保持语言与原意，修正语法和改善自然度。 |
| 翻译并替换 | 一次明确触发翻译，并在结果生成后直接写回原选区。 |
| 润色并替换 | 一次明确触发润色，并在结果生成后直接写回原选区。 |
| 目标映射 | 用户配置的「源语言 → 目标语言」规则，用于在没有显式指定目标语言时决定翻译目标；一个源语言只对应一个目标。 |
| 兜底目标 | 映射中没有对应源语言或无法可靠检测源语言时使用的目标语言，默认简体中文。 |
| 学习内容 | 可选生成的词汇、搭配、句式与释义，不等于收藏。 |
| 收藏条目 | 用户主动保存的表达，词汇、短语和整句统一处理。 |
| 语境 | 收藏表达出现的原句、对应释义，以及适用时的润色前后对照。 |
| 生词本 | 用户收藏的统一列表，不代表其中内容都未掌握。 |
| 释义 | 对表达含义的说明，由模型生成，用户可改；重新生成时被覆盖。语言跟随收藏时的翻译目标，随条目保存。 |
| 笔记 | 用户手写的个人备注，与释义分开保存；自动流程不触碰。 |
| 标签 | 用户给条目加的自由分类词；没有条目引用时自然消失。 |
| 重点 | 用户对条目的二值标记，用于筛选；不表示掌握度。 |
| 读音 | 表达的发音标注；体系（IPA / 假名 / 拼音 / 罗马字）按语言在设置中配置，随条目保存。 |
| 词性 | 表达的语法类别；整句不标。 |
| 历史 | 翻译与润色已生成结果的本地记录，不持有原选区的写回权限。记录原文所在的 App，并关联从该记录收藏的词条。 |
| 来源 | 收藏条目的出处——入口（划选／学习推荐／历史）与原文所在的 App；不随历史删除。 |
