# BDR-0005：释义语言跟随翻译目标

状态：已接受（2026-10-04，待实现）。**2026-10-12 修订 §3**：释义语言改为「生成时按当下映射」，不再随条目冻结；条目上的语言字段改为记录「已存释义实际的语言」。来源：用户需求——「meaning 不一定都是中文，应该是目标语言」。

取代 [LLM 契约](../../llm/contract.md) 中「`meaning` 使用中文」与 `spec/product.md` 「以中文解释」。推荐内容的结构、学习开关、不另设释义语言选择器（`recommendations.feature`）都不变。

## 用户价值与动机

今天三处 prompt 写死简体中文：`ModelClient.swift:130`「给出简体中文释义」、`:190`「用简体中文解释含义与用法」、`:196`「meaning is Simplified Chinese」。读英文、日文时这是对的。但用户同时做「写中文→译成英文」这个方向：收藏一条中文表达，模型被要求用中文解释中文，只能绕成夹着英文对应词的释义，对练英文写作没有价值。

释义语言跟着翻译目标走，收藏时的释义语言与用户当时在练的语言一致。这与 [BDR-0003](../../settings/decisions/BDR-0003-translation-target-mapping.md) 的思路相同：方向跟着文本走，用户不必维护状态。

## 决定

### 1. 翻译场景：释义 = 本次目标语言，严格

不论表达取自原文还是译文，释义都用本次翻译的目标语言。中→英翻译后从译文收藏一条英文短语，释义是英文——会出现英释英，接受。

备选「对侧语言」（表达是英文就用中文解释，反之亦然）不采纳：要判断表达属于翻译对的哪一侧，从译文里手选片段时这个判断并不可靠（片段可能混写）；而「= 目标语言」只有一条规则，没有判断。

### 2. 润色场景：按目标映射查原文语言，未命中用兜底目标

润色没有目标语言（结果语言 = 原文语言），于是复用 BDR-0003 的映射表与兜底目标：润色英文 → 查「en → ?」得中文；润色中文 → 查「zh-Hans → ?」得英文；原文语言不在映射里 → 兜底目标（默认中文）。不加新设置。

备选「润色固定中文」不采纳：润中文时得到中文释义，对写作方向无用，与翻译场景的规则不一致。

### 3. 生成与重新生成都按当下的映射

首次生成释义时按当时的映射算出语言；之后在生词本里「补充释义」「重新生成」，**仍按当下的映射表现算**，而不是读条目上记的旧语言。映射表改了，用户主动重新生成就会换语言——这是他要的结果，因为换映射正是为了换练习方向。

条目上仍保留语言字段，但它记的是**已存释义实际的语言**，供展示与「是否需要重新生成」的判断用，不再作为请求的输入。

不自动重算是刻意的：映射一改就批量重发请求会让一次设置变更触发 N 次模型调用，还要处理部分失败。改为详情里给一个「按当前设置重新生成」入口，一次一条。

从历史详情收藏时沿用同一规则：翻译记录的 `language` 就是目标语言，润色记录的 `language` 就是原文语言——现有字段恰好各是所需的那个，历史不必补存源语言。

### 4. 不加设置、不加选择器、不回填

- 不在设置里提供「释义语言」开关：三选一时已否决；一个全局设置满足不了双向使用。**注意**：后来新增的「母语」设置（[BDR-0012](BDR-0012-native-language.md)）不是释义语言设置，它只决定学习内容包含哪些条目，不参与释义语言的计算。
- 学习区不另设释义语言选择器（`recommendations.feature` 现有规则保留）。
- 升级前的条目不回填：内容不动，释义语言记为简体中文——这与它们实际的语言一致。

## 影响

- `spec/learning/features/definition-language.feature`（新增）：以上规则的场景。
- `spec/learning/features/recommendations.feature`：润色学习场景去掉「用中文」。
- `spec/vocabulary/features/collection.feature`：「中文语境释义」「补充中文释义」去掉「中文」。
- `spec/llm/contract.md`：`meaning` 语言规则改写；请求须携带释义语言，校验可按语言 tag 检查返回。
- `spec/product.md`：「以中文解释」改写。
- 术语：「学习内容」定义去掉「中文」；「释义」定义补语言规则（待确认）。
- 数据：条目新增释义语言字段（`definitionLocale`，见 `docs/vocabulary-schema-v2.html`）；旧数据默认 `zh-Hans`。
- 实现：三处 prompt 改为注入语言；`LearningRequest` 已带 `targetLanguage`，润色时改为传映射查得的语言；`CollectionAction.fillMeaning` 读条目字段而非常量。

## 明确不做

- 不做释义语言设置项。
- 不做学习区语言选择器。
- 不回填旧条目。
- 不让历史补存源语言。
