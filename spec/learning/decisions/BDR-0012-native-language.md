# BDR-0012：学习内容不含母语

状态：已确认（2026-10-12，待实现）。来源：用户需求——「学习内容不包含母语」。

## 用户价值与动机

用户母语为中文，主要用它练习英语、日语。翻译一段日语到中文时，原文与译文两侧都可能被推荐：日语的表达值得学，中文的搭配对他没有价值。与其让他每次自己忽略，不如声明一次母语，之后学习内容自动跳过它。

## 决定

### 1. 母语是一个设置，不是一份排除名单

设置里选「母语」（单选，默认未指定），语义是「这是我的语言」。凡是母语的表达都不进学习内容。不提供「不学习哪些语言」这类黑名单——黑名单要求用户预先想到所有不学的语言，而母语只有一个事实。

候选语言只用应用在用的那些语言（`SettingsStore.languages()`），不列系统全部语言。

### 2. 放在「语言」页的映射表旁

候选语言就是在那里定义的目标映射与兜底目标，放在一起用户不必跨页对照。

### 3. 只影响学习内容，不影响释义语言

释义语言仍按 [BDR-0005](BDR-0005-definition-language.md) 计算（翻译跟随本次目标，润色按映射查原文语言）。母语不参与该计算——否则「母语=中文、翻译成中文」会让释义语言变成中文之外的东西，与用户正在练的方向脱节。

### 4. 两种操作的学习内容都受约束

翻译：跳过母语那一侧的条目（日语→中文、母语=中文 → 只推荐日语表达）。
润色：原文与结果同语言，所以母语文本**不产生学习内容**——此时不发起请求，也不显示学习入口，省一次模型调用；润色非母语文本照常推荐。

### 5. 提示词约束 + 本地过滤

请求里告诉模型不要推荐母语表达，收到返回后仍按 `item.language` 过滤一遍。模型不保证听话，本地过滤保证生效。

## 影响

- `spec/learning/features/recommendations.feature`：新增「学习内容不含母语」规则与场景。
- `spec/settings/features/target-mapping.feature`：新增「母语只影响学习内容」规则（位置、默认值、边界、持久化）。
- `spec/product.md`：学习一段补上母语的作用范围。
- 数据：设置新增一项（母语，默认空）。
- 实现：学习请求构造时按母语过滤条目；润色母语文本时判定为「无学习内容」。
