# BDR-0019 · 屏幕区域 OCR 输入

状态：已接受，已实现（2026-10-23）。设计全文见 [screen-region-input.zh-CN.md](../../../docs/screen-region-input.zh-CN.md)；本决策裁定其中待定项，并推翻其中两条。

## 裁定

1. **独立的全局快捷键「翻译屏幕区域」。** 只做翻译：截图里的文字没有可写回的地方，润色别人的文字也没有意义。无默认组合。
2. **框选用系统的 `screencapture -i`，不自己画覆盖窗口。** 推翻提案里的「只由应用自己画」：系统的十字准星、Esc 取消、空格切换窗口模式与多显示器都现成可用，也符合「只用原生组件」。截图写到临时文件，读出后立即删除。
3. **先检查屏幕录制权限。** `CGPreflightScreenCaptureAccess()` 为假时调一次 `CGRequestScreenCaptureAccess()`；仍为假就显示紧凑提示与「屏幕录制设置」入口，不进入框选。
4. **OCR 用本机 Vision。** `RecognizeTextRequest`，精确识别，自动检测语言；各行按坐标自上而下拼接，不检测分栏，顺序交给模型兜底。
5. **截图保留，以缩略图出现。** 推翻提案里的「截图不保留」。Vision 读原图，保存的是缩小后的副本（最长边 1280 像素、JPEG 质量 0.6）；截图不发给模型，也不进调试日志。按 UI/UX 评审：
   - 紧凑原文条与没有内容时，缩略图（约 38pt 高，圆角按设计图为 8pt，放大后为 14pt）在原文**左侧**；第一段译文到达、面板展开时，同一个缩略图随展开的弹簧动画移到**右侧**（`matchedGeometryEffect`，减少动态效果时直接切换）。分区显示下在上方原文的右上角、分割线以上，原文绕着它排（TextKit 排除区域；SwiftUI 文本做不到环绕，所以只有这个原文框是 `NSTextView`）；逐句对照下在句对区右上角。
   - 悬停显示系统放大镜光标。点缩略图就地放大：原文隐藏，截图占满宽度；再点缩回，原文回来，过程随弹簧动画（减少动态效果时直接切换）。紧凑原文条里点缩略图则直接展开为放大状态。不用 popover。
   - 历史列表行：时间行占满整行，缩略图在译文、原文两行左侧，圆角与列表选中背景一致。历史详情：截图与正文都撑满详情区，图片带一道系统分隔线色的细边框（DESIGN.md 的封闭例外），不加底色、文字或按钮；悬停显示放大镜光标，点击用 Quick Look 放大。
6. **结果默认显示缩略图，可设为放大。** 设置「通用 › 浮窗」的「屏幕区域截图」可选「缩略图」（默认）或「放大」：选放大时，面板展开到结果就是截图占满宽度、原文隐藏的状态；点击照样切换。
7. **没有文字时照着截图输入；截图失败时回到输入框。** 识别不出文字时，浮窗直接展开，截图以放大状态占满宽度，下面是空的原文输入框并获得焦点，原因写在占位文字里（「截图里没有识别出文字，照着输入后按 ⌘↩」）；按 ⌘↩ 后照常翻译，截图保留。截图本身失败时，按 BDR-0018 落到读不到选区时的原文条输入框。原文条输入框支持粘贴图片：剪贴板里只有图片、没有文字时，⌘V 把图片当作截图识别并翻译，识别不出文字则进入上面的状态。模型失败（连接、未配置、格式）沿用普通翻译的形态：原文条（缩略图与识别出的文字）下方一个错误条。缺少屏幕录制权限的紧凑提示不变。屏幕区域的面板右下角有「重新框选」。（2026-10-24 评审确认。）
8. **框选时按 Esc 什么都不发生。** 不显示提示。
9. **「模型读图」暂不做。** 等模型层能携带图片后再议。

## 影响

- `ShortcutAction` 增加 `translateRegion`；菜单栏菜单与快捷键页自动列出。
- `HistoryRecord` 增加可选的 `sourceImage`（轻量迁移）。
