# BDR-0019 · 屏幕区域 OCR 输入

状态：已接受，已实现（2026-10-23）。设计全文见 [screen-region-input.zh-CN.md](../../../docs/screen-region-input.zh-CN.md)；本决策裁定其中待定项，并推翻其中两条。

## 裁定

1. **独立的全局快捷键「翻译屏幕区域」。** 只做翻译：截图里的文字没有可写回的地方，润色别人的文字也没有意义。无默认组合。
2. **框选用系统的 `screencapture -i`，不自己画覆盖窗口。** 推翻提案里的「只由应用自己画」：系统的十字准星、Esc 取消、空格切换窗口模式与多显示器都现成可用，也符合「只用原生组件」。截图写到临时文件，读出后立即删除。
3. **先检查屏幕录制权限。** `CGPreflightScreenCaptureAccess()` 为假时调一次 `CGRequestScreenCaptureAccess()`；仍为假就显示紧凑提示与「屏幕录制设置」入口，不进入框选。
4. **OCR 用本机 Vision。** `RecognizeTextRequest`，精确识别，自动检测语言；各行按坐标自上而下拼接，不检测分栏，顺序交给模型兜底。
5. **截图保留，以缩略图出现。** 推翻提案里的「截图不保留」。Vision 读原图，保存的是缩小后的副本（最长边 1280 像素、JPEG 质量 0.6）；截图不发给模型，也不进调试日志。按 UI/UX 评审：
   - 紧凑原文条与没有内容时，缩略图（约 38pt 高，系统同心圆角 `ConcentricRectangle`）在原文**左侧**；第一段译文到达、面板展开时，同一个缩略图随展开的弹簧动画移到**右侧**（`matchedGeometryEffect`，减少动态效果时直接切换）。分区显示下只在上方原文的右侧、分割线以上；逐句对照下在句对区右上角。
   - 点缩略图用系统 popover 显示原尺寸（固定尺寸，避免与浮窗互相调整大小）。
   - 历史列表行：时间行占满整行，缩略图在译文、原文两行左侧。历史详情：截图放在无标题的系统 `GroupBox` 上居中，右下角一个玻璃放大按钮；不加文字，点图或按钮用 Quick Look 放大。
6. **读不到时走手动输入。** 截图失败或识别不出文字时，按 BDR-0018 原文条变成空的输入框，缩略图在左侧，占位文字为「截图里没有识别出文字，照着输入后按 ⌘↩」，右侧多一个「重新框选」按钮。
7. **框选时按 Esc 什么都不发生。** 不显示提示。
8. **「模型读图」暂不做。** 等模型层能携带图片后再议。

## 影响

- `ShortcutAction` 增加 `translateRegion`；菜单栏菜单与快捷键页自动列出。
- `HistoryRecord` 增加可选的 `sourceImage`（轻量迁移）。
