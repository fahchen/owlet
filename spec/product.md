# macOS 翻译与润色工具：首版产品定义

## 产品定位

一款采用类 Raycast 浮窗交互的 macOS 工具：选中文本后，通过快捷键翻译或润色，并将需要学习的词汇、短语、整句手动收进个人生词本。

首先服务个人使用。用户母语为中文，主要使用英语、日语，但产品不绑定特定语言或内容领域，覆盖日常阅读、写作及工作沟通。

## 系统支持

最低支持 macOS Tahoe 26.0（引入 Liquid Glass 的版本），不兼容更早系统。

## 核心流程

### 翻译

选中文本 → 翻译快捷键 → 浮窗展示译文 → 复制结果或主动替换原选区 → 按需收藏。

- 自动识别原文语言，默认目标语言为中文。
- 翻译预览按句成组，上方原文、下方对应译文；中英逐句对齐，换行不改变对应关系。复制和替换仅输出译文。
- 可切换目标语言，并记住选择。
- 没有可读取的选区时，可在浮窗输入或粘贴文本。

### 翻译并直接替换

选中文本 → “翻译并替换”快捷键 → 按当前目标语言翻译 → 校验原选区 → 直接写回，无需再点击替换。

- 使用独立、可配置的全局快捷键；沿用最近选择的目标语言，默认中文。
- 仅对可编辑且可可靠定位的原选区写回。没有有效选区时提示并进入手动输入，不自动替换。
- 翻译失败、请求取消或被新操作取代时，不写回；原文或选区变化时保留译文供复制。
- 与普通翻译一样保存历史；译文生成成功但替换失败时仍保留翻译记录。
- 沿用翻译学习开关；学习内容的生成不阻塞替换，也不触发自动收藏。

### 润色

选中文本 → 润色快捷键 → 浮窗展示润色结果及修改对照 → 复制结果或主动替换原选区 → 按需收藏。

- 保持原文语言与原意，修正语法、改善自然度。
- 默认给出一个结果，不提供多版本或语气预设。
- 区分语法修正与风格优化，不将风格偏好描述为错误。

### 两种界面形态

- 翻译、润色、翻译并替换三个快捷键均唤起同一个类似 Raycast 的紧凑浮动工具栏，并进入对应模式：无侧栏、无完整应用框架，按需展开结果与学习内容，Esc 收起。
- 翻译与润色处理中仅显示单行紧凑条：小指示器、选中文字摘要、加载状态及取消入口；完成后动画展开结果。减少动态效果开启时直接切换。
- 工具栏提供操作切换，以及进入生词本、历史和设置的入口。
- 生词本、历史与设置使用独立的完整管理窗口；后续复习也属于该窗口，首版仍不实现复习。
- 翻译并替换保持独立快捷键，不依赖先打开完整管理窗口。

### 浮窗与替换

- 翻译、润色、翻译并替换分别使用可配置的全局快捷键。
- 支持键盘操作，Esc 关闭浮窗。
- 普通翻译／润色由用户点击替换后写回；“翻译并替换”快捷键明确授权本次翻译完成后直接写回。
- 原选区失效或无法安全定位时，提示无法替换，保留结果供复制。
- 从历史查看的结果可复制；不沿用历史操作的原选区执行替换。

## 学习内容与收藏

- 翻译、润色分别设置学习内容开关，默认关闭。
- 关闭时不自动生成或展示学习内容；可在单次操作中临时展开，不改变长期设置。
- 开启后，推荐值得学习的词汇、搭配或句式，以中文解释，不强行凑数量。
- 润色学习内容说明修改前后的差异及原因。
- 无论学习开关是否开启，都可手选原文或结果中的片段收藏。
- 不自动收藏。推荐内容可勾选入库，手选内容可直接收藏。
- 点击收藏即保存，不强制填写表单，之后可编辑。
- 词汇、短语、完整句子统一收藏，用户无需先分类。
- 条目保留表达、语言、原句与语境释义；润色条目同时保留修改前后对照。
- 同一表达再次收藏时，可向已有条目追加新语境；不同语言的同形表达不自动合并。

## 个人生词本

- 本地保存用户主动收藏的内容。
- 支持列表、详情、搜索、按语言筛选、编辑、删除及导出。
- 首版仅管理与展示收藏，不包含复习流程或掌握度判断。

## 历史记录

- 自动保存翻译、润色操作的原文与结果，并记录操作类型、语言及时间。
- 提供历史列表与详情，支持搜索、按翻译／润色筛选。
- 可复制历史结果，也可从历史内容中收藏。
- 支持删除单条历史、清空全部历史；不自动过期。
- 历史与生词本独立：删除历史不删除已经收藏的条目及其原句语境。

## 模型与数据设置

- 用户自行填写 OpenAI 兼容接口的 Base URL、API Key、模型名。
- API Key 存入 macOS 钥匙串。
- 历史、生词本及应用设置保存在本机。
- 翻译、润色及学习内容生成使用用户配置的模型服务，相关文本会发送至该服务；本地存储不等于离线推理。

## 首版不做

- 复习、间隔重复、学习提醒、学习计划：首版只负责处理文本与积累内容。
- 自动收藏、复杂语言水平评估、掌握度推断：由用户决定保存什么。
- 多端同步、账号体系、社交功能：先提供完整的单机使用体验。
- 独立课程、多版本润色、语气模板：保持核心交互简洁。

## 定义边界

本文定义产品行为与首版范围，不包含验证实验或成功指标。应用名称、具体快捷键、导出格式及技术实现留待实现阶段确定，不扩展上述范围。
