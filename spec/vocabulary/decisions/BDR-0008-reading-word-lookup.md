# BDR-0008：阅读中查词，明确触发且不自动入库

状态：已确认（2026-10-07）；五类区域已实现（T48–T51，2026-10-11），待最终验收。来源：[查词意图](../../../docs/intent/word-lookup.md)与 Suikou 审阅。

范围：阅读场景里的查词卡，提供解释、读音与发音。查询输入框、查询历史、结果入库与写回留待第二阶段。

## 决定与理由

- **只读正文单击查词，选区须明确查询。** 浮窗、文本处理页只读结果、生词本详情与历史详情保留单击快路径；系统分词不合意时手选修正，工具栏「查询」与右键「查询所选」严格使用手选范围。选中本身只显示操作工具栏，避免阅读、复制或拖拽时意外请求。单击不再用于只读正文放置光标，保留双击选词、拖拽与复制。
- **学习行仍点击收藏／取消收藏，可编辑字段仍可编辑。** 学习行只从选区入口查词，拖拽不能误触收藏；原文输入框与生词本编辑字段不改成只读。拒绝为统一查词手势而改变这些既有行为。
- **解释当前语境中的意思，缺少原句时给一般含义并标明无语境。** 局部语境须覆盖完整选区，不默认发送整篇正文，不编造来源句。拒绝强制列完整多义项：当前阅读只需理解文中义。释义语言沿用 [BDR-0005](../../learning/decisions/BDR-0005-definition-language.md)，接受英释英，不新增语言选择器。
- **查询词形作标题，模型原形作次级信息。** 不在本地猜原形，不为缺失字段编造内容；原形相同不重复显示。读音体系沿用 [BDR-0006](BDR-0006-on-demand-enrichment.md)，读音未知允许空，整句不显示读音与词性。
- **相同查询条件复用；跨句旧解释显示来源，主动重查后才成为当前句解释。** 跨句候选须有真实来源语境，词形、已知文本语言与解释设置须兼容；无语境一般义仅按无语境条件精确复用，不按原形猜跨词形复用。同条件进行中不重复请求；失败后再次打开不自动重发，须明确重试。重查失败保留可读旧解释及旧来源，成功只更新当前条件结果。只做有容量上限、退出清空的内存复用，不引入持久查询历史。
- **系统语音手动朗读查询词形，模型读音供阅读。** 打开不自动播放，再次播放中断旧音，关闭或切换卡片停止；没有可用语音或文本语言未知时保留禁用按钮并说明原因，释义仍可用。不宣称系统 TTS 是句中异读的权威音频。拒绝系统词典富文本：不能稳定提供本卡片所需字段与语境义；拒绝外部词典音频：首步无需增加服务依赖。暂不新增语音偏好设置。
- **只显示当前查词卡，Esc 先关卡片再按原有浮窗规则处理。** 迟到响应不能覆盖新查询或让已关闭卡片弹回；卡片操作保留阅读选区与浮窗。键盘与 VoiceOver 须能发现并触发查询、获知状态及回到正文，不能依赖悬停。
- **查词结果只供当场阅读。** 查询、重查与播放不收藏、不覆盖生词本字段、不写回正文或来源应用。与条目详情「补充缺失／重新生成」分开，后者仍按 BDR-0006 处理。

## 规格与落地边界

- 行为见 [word-lookup.feature](../features/word-lookup.feature)。独立查词约定与本地校验沿用现有模型诊断及不记录 API Key 的要求；返回结构、查询对应关系与语言标识可校验，不承诺程序能证明语义、原形或读音准确。
- 悬停反馈只使用设计规范允许的系统反馈，不改变文本布局；选中态不叠加悬停。原生文本承载、手势识别时机、焦点与辅助功能须验证后落地，不预定五处全部替换控件。
- 长度上限（T48 确定）：查询文本 300 字，超出时「查询」禁用并说明原因；局部语境 1200 字，超出时取以选区为中心且完整包含选区的片段。不截断选区。
- 承载（T48 原生验证）：只读结果用 TextKit 1 的只读 `NSTextView`，选区工具栏与卡片共用一个系统 `NSPopover`。工具栏出现时把键盘交还正文，键盘扩选不中断；卡片弹出窗口可接收键盘焦点以便 Tab 到按钮。Esc 先由浮窗关闭弹出层再关浮窗。
