# 实现计划：macOS 翻译与润色工具

状态：里程碑 1（T01–T07）已实现并有单元测试覆盖，里程碑 2–5（T08–T25）尚未实施；计划其余内容仍待用户审阅。产品范围以 `spec/product.md` 为准，行为场景见 `spec/README.md`。

## 概述

实现翻译、润色、翻译并替换三个全局快捷入口，支持复制与安全替换、可选学习内容、手动收藏、本地生词本和历史记录。不实现复习、同步或学习水平评估。本计划中的检查均为实现正确性验收，不是产品需求验证实验。

## 当前基础与技术建议

当前已有产品规格及 `design/index.html` 交互原型；已建立原生工程（`project.yml` 生成 `Owlet.xcodeproj`）与 `mise run check` 质量门槛，并已实现里程碑 1 的手动输入翻译、JSON 契约、快捷键录制、选区读取、安全写回、翻译并替换与润色（源码在 `Owlet/` 的 App、LLM、Processing、Selection、Settings、Shortcuts 目录，`OwletTests/` 下有对应单元测试）。原型检查不代表原生系统兼容性已验证。以下沿用建议技术起点。

- 即时操作使用无侧栏的紧凑浮动工具栏；应用内统一文本处理页面、设置、生词本和历史使用完整管理窗口，后续复习属于管理窗口但不纳入首版。
- 原生 SwiftUI 构建设置与列表，AppKit 管理浮窗、文本选择与应用焦点；不引入 Web 容器或后端服务。
- 最低支持 macOS Tahoe 26.0（引入 Liquid Glass 的版本），不支持更早系统；使用 SwiftData 保存历史与收藏，UserDefaults 保存普通设置，Keychain 保存 Key。工程使用 macOS 26 或更新 SDK，Deployment Target 设为 26.0。
- URLSession 调用 OpenAI 兼容的 Chat Completions 接口；所有模型消息内容必须返回并通过 JSON 契约校验；支持时采用供应商结构化输出，不支持时仍要求 JSON 并严格校验，不回退纯文本。设置的 Base URL 定义为 API 根路径，清晰展示最终请求地址。
- 先显示完整结果，不将流式响应列为首版要求。请求可取消，旧响应不得覆盖新操作。
- 原生辅助功能接口读取选区；打开前缺权限或配置时显示紧凑提示及对应设置入口，读取失败提供进入完整窗口的手动输入入口。已展开的工具栏遇错保留界面，在内容区提示并提供恢复入口；仅在没有运行中的所属应用、没有辅助功能权限或无法前置所属应用时拒绝写回。
- 历史不保存可执行的外部选区引用。收藏独立保存语境，删除历史不级联删除收藏。
- 选区（已确认）：优先辅助功能接口读取，读不到再模拟 ⌘C 并恢复剪贴板。写回不比较选区文字，也不用辅助功能写入（应用会「报告成功但什么也没改」）：面板先让出键盘、前置所属应用，再合成 ⌘V，用元素文本的前后对比确认是否落盘；只在无权限、无法前置或选区明确不可编辑时拒绝。
- 快捷键（已确认）：无默认组合，用户录制后才注册；“恢复默认”即清除。
- 应用形态（已确认）：仅菜单栏图标，无 Dock 图标（`LSUIElement`），主窗口由菜单栏打开。
- 分发（已确认）：不启用 App Sandbox（跨应用辅助功能需要），本机签名自用；共享构建时再加 Developer ID 与公证，不上架 Mac App Store。
- 存储（已确认）：SwiftData，默认 Application Support 单一 store，无同步。`HistoryRecord`（T15）保存操作、原文、结果、语言、时间，不含选区引用。`VocabularyEntry`（T08）按语言＋去首尾空白表达 `#Unique`（T11），`VocabularyContext` 以 cascade 挂在条目下并复制原句快照；收藏与历史之间无关系，删除历史不可能级联。测试用内存 `ModelConfiguration`，每测试独立容器。首次重命名或删除字段时再引入 `VersionedSchema`；数据量使搜索变慢时再评估 SQLite FTS。
- 导出建议采用 UTF-8 JSON，保留所有语境与润色对照；首版不做导入。
- 逐任务增加模型字段，不提前建设复习表、同步协议或多供应商适配框架。

## 工程与验证约定

源码目录 `Owlet/`、测试 `OwletTests/`；工程由 XcodeGen 按 `project.yml` 生成，不入库。所有任务复用：

```sh
mise run test    # 生成工程并运行 OwletTests
mise run check   # lint + test，pre-commit 与 CI 同用
```

命令已在工程初始化时验证通过。各任务仅运行相关测试与构建，检查点运行已有测试全集及手工流程。模型网络测试用固定响应与失败响应，不让日常自动测试消耗真实 API；实际配置的服务另做一次端到端检查。不修改跨测试共享的运行时配置。

## 风险与处理

| 风险 | 影响 | 处理 |
|---|---|---|
| 应用不公开选区、或选区在读取后变化 | 读错或覆盖其他文字 | 读取按聚焦元素、祖先、子树、窗口逐层退让，仍失败则用 ⌘C 复制；写回前用 `AXRole` 确认选区可编辑，读不回元素文本时不算失败 |
| 浮窗切换焦点后原选区或其元素不再可达 | 写回落到应用当前焦点 | 粘贴不依赖捕获到的元素：面板让出键盘并前置所属应用后合成 ⌘V；元素读不回来不算失败，只有文本确实没变才拒绝，结果仍可复制 |
| 兼容接口返回格式或错误不同 | 请求失败、结果无法展示 | 明确接口范围；校验响应、展示可重试错误，不要求供应商专属能力 |
| 请求交错与重复点击 | 展示旧结果、重复历史或收藏 | 操作标识、取消与保存幂等在各自首个消费任务中加入 |
| 把所有错误统一收起或统一展开 | 打断已有上下文，或展示无法使用的工具栏 | T02 起按打开前／展开后分别验证相同错误；设置入口指向当前操作对应配置 |
| 学习推荐关闭仍触发额外分析 | 违背设置及增加调用 | T10 验证未点击不请求，T13 验证开关关闭不请求；手动收藏释义为明确操作，独立处理 |
| 历史删除牵连收藏 | 用户内容丢失 | T08 独立语境快照，T17 加删除历史后的回归检查 |
