# 实现计划：macOS 翻译与润色工具

状态：计划已编写，尚未实施，待用户审阅。产品范围以 `spec/product.md` 为准，行为场景见 `spec/README.md`。

## 概述

实现翻译、润色、翻译并替换三个全局快捷入口，支持复制与安全替换、可选学习内容、手动收藏、本地生词本和历史记录。不实现复习、同步或学习水平评估。本计划中的检查均为实现正确性验收，不是产品需求验证实验。

## 当前基础与技术建议

当前目录仅有产品文档，没有应用工程、构建命令或现存测试。以下是实现起点，不声称已验证系统兼容性。

- 原生 SwiftUI 构建设置与列表，AppKit 管理浮窗、文本选择与应用焦点；不引入 Web 容器或后端服务。
- 最低支持 macOS Tahoe 26.0（引入 Liquid Glass 的版本），不支持更早系统；使用 SwiftData 保存历史与收藏，UserDefaults 保存普通设置，Keychain 保存 Key。工程使用 macOS 26 或更新 SDK，Deployment Target 设为 26.0。
- URLSession 调用 OpenAI 兼容的 Chat Completions 接口；首版不依赖供应商独有能力或强制结构化输出。设置的 Base URL 定义为 API 根路径，清晰展示最终请求地址。
- 先显示完整结果，不将流式响应列为首版要求。请求可取消，旧响应不得覆盖新操作。
- 原生辅助功能接口读取选区；取得权限前仍可手动输入。不能可靠读取时允许粘贴，不能确认原选区时拒绝替换。
- 历史不保存可执行的外部选区引用。收藏独立保存语境，删除历史不级联删除收藏。
- 导出建议采用 UTF-8 JSON，保留所有语境与润色对照；首版不做导入。
- 逐任务增加模型字段，不提前建设复习表、同步协议或多供应商适配框架。

## 任务顺序与依赖

详细验收、文件范围和验证方式见 `tasks/todo.md`。每项作为独立、可运行、可提交的增量；没有 git 仓库时不自动初始化或提交。

5. T04 润色与修改对照。依赖 T03。
6. T05 持久化历史及详情。依赖 T04。
7. T06 历史搜索与删除。依赖 T05。
8. 检查点 B：两种操作与历史。
9. T07 手动收藏与生词本列表。依赖 T05。
10. T08 收藏编辑、筛选、删除与导出。依赖 T07。
11. 检查点 C：收藏管理。

## 工程与验证约定

预计目录 `LanguageAssistant/`、`LanguageAssistantTests/`；名称是占位工程名，不代表最终产品名。T01 创建共享 Xcode scheme `LanguageAssistant` 并固定如下命令，后续任务复用：

```sh
xcodebuild -project LanguageAssistant.xcodeproj -scheme LanguageAssistant -destination 'platform=macOS' build
xcodebuild -project LanguageAssistant.xcodeproj -scheme LanguageAssistant -destination 'platform=macOS' -only-testing:LanguageAssistantTests test
```

命令需在 T01 工程创建后核实；当前未执行。各任务仅运行相关测试与构建，检查点运行已有测试全集及手工流程。模型网络测试用固定响应与失败响应，不让日常自动测试消耗真实 API；实际配置的服务另做一次端到端检查。不修改跨测试共享的运行时配置。

## 风险与处理

| 风险 | 影响 | 处理 |
|---|---|---|
| 应用不公开选区、选区或文档已变化 | 读错或覆盖其他文字 | T02、T03 提前处理；验证来源元素、文档与选区，不可靠时只复制 |
| 浮窗切换焦点使原选区失效 | 替换失败 | 唤起前保存会话内来源上下文，写回前重新检查；绝不盲发粘贴快捷键 |
| 兼容接口返回格式或错误不同 | 请求失败、结果无法展示 | 明确接口范围；校验响应、展示可重试错误，不要求供应商专属能力 |
| 请求交错与重复点击 | 展示旧结果、重复历史或收藏 | 操作标识、取消与保存幂等在各自首个消费任务中加入 |
| 学习推荐关闭仍触发额外分析 | 违背设置及增加调用 | T09 验证关闭时不请求学习推荐；手动收藏释义为明确操作，独立处理 |
| 历史删除牵连收藏 | 用户内容丢失 | T07 独立语境快照，T08 加删除历史后的回归检查 |
